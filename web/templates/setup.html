Whoever opens this page first could claim the server, so setup needs the setup token. It is printed in the server log when the server starts (look for setup token), or it is the SETUP_TOKEN you set.

Administrator password

Protects this console. At least 12 characters; use a password manager.

Where should images be stored?

This server uses Postgres, which usually means a platform without a persistent disk (such as DigitalOcean App Platform). Local files would vanish on every deploy: choose a bucket.

To store a bucket secret, set a SECRET_KEY environment variable (at least 32 characters, e.g. openssl rand -hex 32) and restart. The secret is encrypted with it.
